# My Favorite Series

## Game of Thrones

**Game of Thrones** is a dark fantasy series about how power corrupts people and how petty politics blind leaders to real danger. It is set in a Medieval world, it follows several noble families fighting a brutal civil war while a deadly supernatural threat marches toward them from the frozen North.

### Why I Like It
- Interesting characters
- Exciting story
- Mystery and fantasy

### Favorite Character
My favorite character in Game of Thores is Daenerys Targaryen and Jon Snow
